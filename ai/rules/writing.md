# Writing style

This applies to code comments and docstrings, markdown files, reports, static
pages, commit messages, pull request descriptions, Slack and Jira drafts, and
agent instruction files. Chat replies follow `claude-context.md` instead.

Write as a Wikipedia editor would: neutral, specific and plain. State the facts
and the reasons, and leave out the framing.

Avoid:

- inflated vocabulary: delve, leverage, robust, seamless, comprehensive,
  crucial, pivotal, landscape, tapestry, testament, showcase, streamline;
- filler phrases: "it's worth noting", "it's important to", "in order to",
  "at its core";
- set constructions: "not X but Y", "not only ... but also", lists of three
  added for rhythm, rhetorical questions;
- chains of em dashes, emoji, bold scattered through the text, and capital
  letters for emphasis;
- promotional or reassuring tone, and closing summaries that repeat the text;
- self-reference: "as an AI", "Claude suggests", "generated by", or remarks
  about the writer's own process.

For anything longer than about a page, load the `wikipedia-ai-writing` skill
while drafting and run the `deslop` skill on the result.
